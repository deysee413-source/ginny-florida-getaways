# Ginny Adkins | Florida Getaways

Website for Sunseeker Getaway (South Daytona, FL) and Serenity Sprout Retreat (Deltona, FL), hosted by Airbnb Superhost Ginny Adkins.

- `index.html` contains the whole site. Site settings (contact info, social links, form endpoint, placeholders) are in the `CONFIG` block at the top of the script.
- `img/` holds the property photos.
- Bookings go through the official Airbnb listings. This site takes no bookings or payments.
